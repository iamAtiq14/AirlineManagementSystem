## Project Overview
The Airline Management System is an academic/university project built using the .NET framework. It aims to provide foundational functionalities for managing airline operations such as flight booking and passenger management.

*Note: This is an academic project.*

## Features
- **Flight Management:** Administrative tools to manage flights.
- **Booking System:** Functionality for booking flights.
- **Passenger Management:** Tools to handle passenger information and records.

## Tech Stack
- **Framework:** ASP.NET MVC
- **Frontend Scripting:** JavaScript
- **Database:** SQL Server

## Getting Started

### Prerequisites
- Visual Studio (with ASP.NET and web development workloads)
- SQL Server

### Setup Instructions
1. Clone the repository.
2. Open `AirlineManagementSystem.sln` in Visual Studio.
3. Configure your SQL Server database connection string in `Web.config`.
4. Build the solution to restore NuGet packages.
5. Run the application via IIS Express in Visual Studio.
